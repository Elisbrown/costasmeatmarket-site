# costasmeatmarket-site

Static site for Costa's Meat Market (Davenport, FL) in English, Spanish and Portuguese, generated by Python.

- Build: `python3 _build/build.py`. Never edit generated HTML by hand; change `_build/content/` or `_build/lib/`.
- Test: `python3 -m unittest test_seo_and_discovery` (must pass before every push; the weekly GitHub Action runs it too).

## SEO

Every SEO step taken on this site is saved as the reusable `seo` skill in `.claude/skills/seo/`:
`SKILL.md` has the phase checklist and rules, `reference.md` has each step in detail with templates and gotchas.
Follow it here, and copy the folder into other projects (or `~/.claude/skills/seo/`) to reuse it.
